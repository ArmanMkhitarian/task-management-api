# Инструменты

## Claude Code
Основной инструмент. Через него вёл всё, и согласование архитектуры до кода, и 
генерацию по этапам, и тесты. Пользуюсь каждый день. Удобно что держит контекст, 
читает CLAUDE.md, сам коммитит.

## Отдельная сессия Claude Code для тестов
Тесты писал в отдельной сессии, чтобы был свежий взгляд на готовый код.

## VS Code
Редактор, в нём запускал Claude Code.

## Docker (Colima)
Локальный запуск стека и интеграционные тесты через Testcontainers.

## Модель
Claude Opus 4.8 на подписке Max.
